# AnoPKI Enterprise Overlay

This directory contains private Enterprise-only material.

Current contents are intentionally small and boundary-focused:

- `anocrypto/`: C99 AnoCrypto integration skeleton.
- future `features/`: SSO/RBAC, deploy adapters, SIEM, compliance reports.
- future `packaging/`: customer and release packaging assets.

Keep upstream Community behavior stable and additive. Avoid broad forks of shared
lifecycle code unless the change must also be proposed upstream.
