# KCMVP Preparation Notes

This document is private Enterprise planning material.

## Current status

AnoCrypto is a direction and skeleton in this split package. Do not describe it as
KCMVP-validated until an actual validated module and approved evidence exist.

## Evidence to prepare

- module boundary and approved mode description,
- source and binary configuration inventory,
- compiler, OS, and build option matrix,
- algorithm implementation evidence and test vectors,
- self-test and failure-state behavior,
- key handling and zeroization notes,
- configuration management and change-control records,
- release candidate hashes and customer package manifest.
